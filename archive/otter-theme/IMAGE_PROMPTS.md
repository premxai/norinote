# Nori image prompts

Save each image into `public/mascot/` with the exact filename below. The page picks it up on reload; until then a labelled placeholder shows.

Generate `nori-hero.png` first, then pass it as the character reference for every other image (Midjourney `--cref`, or "image reference" / "character reference" in other tools) so Nori looks the same everywhere.

Every prompt is ready to paste. Each one repeats the same character and style text on purpose.

---

```

Style: flat vector illustration, soft two tone shading, clean rounded shapes, consistent 3px deep navy outlines (#0F172A). Limited palette: chestnut, cream, teal (#0F766E), pale teal (#E3F1EE), sand (#F4EFE6), navy, white. Modern, professional, friendly mascot style of a productivity app. No gradients, no texture, not 3D.

Transparent background, subject centered with generous padding. No text, no letters, no numbers, no logos, no watermark.
```
